# Add & Remove Friend

A small vanilla JavaScript UI demo of a "friend request" card — click **Add** to send a friend request, click **Remove** to withdraw it. Built with plain HTML, CSS, and JavaScript (no frameworks or dependencies).

## Demo

- Click **Add** → status changes to `Request Send!` (green)
- Click **Remove** → status changes to `Request Withdrawn` (red), but only after a request has been sent

## Getting Started

No build tools or installation needed.

1. Clone the repo:
   ```bash
   git clone https://github.com/<rajbirkr>/add-and-remove-friend.git
   cd add-and-remove-friend
   ```
2. Open `index.html` in your browser (or use a live server extension in your editor).
